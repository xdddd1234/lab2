# Library Management System — Лабораторна робота №2

## Опис проєкту

Library Management System — система керування бібліотекою, яка дозволяє вести облік книг, читачів та видач.

Ця лабораторна робота є продовженням лабораторної №1, у якій було створено ER-модель даних із сутностями `Reader`, `Book`, `Author`, `Category` та `Loan`.

## Мета роботи

Описати функціональні та нефункціональні вимоги до бібліотечної системи, створити UML Use Case Diagram і детально розглянути процес видачі книги за допомогою Gherkin-сценаріїв.

У роботі підготовлено 11 функціональних EARS-вимог, 7 нефункціональних вимог (NFR), 5 User Stories, 5 Use Cases та 4 Gherkin-сценарії для видачі книги.
## Артефакти

- `spec.md` — специфікація системи, актори та критерії прийняття.
- `requirements.md` — 11 функціональних EARS-вимог і 7 нефункціональних NFR.
- `user-stories.md` — історії користувачів.
- `scenarios.md` — сценарії Gherkin.
- `use-cases.md` — Use Case Diagram.
- `traceability.md` — матриця трасування вимог і сценаріїв.
- `adr/` — архітектурні рішення за MADR.
- `ai/` — історія промптів та результатів AI-аудиту.
- `DEFENSE.md` — підсумки роботи та обґрунтування рішень.

## Моделювання

Для діаграми використовується PlantUML, для сценаріїв — Gherkin, а для вимог — EARS. Усі артефакти мають відповідати моделі даних із лабораторної №1.
