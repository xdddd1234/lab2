# Use Case Diagram — Library Management System

## 1. Опис

На діаграмі показано основні дії, які можуть виконувати користувачі бібліотечної системи.

Я залишив тільки ті прецеденти, які потрібні читачу або бібліотекарю. Внутрішні перевірки системи не показані як окремі Use Cases.

## 2. Діаграма

![Use Case Diagram](use-cases.svg)

Вихідний код діаграми знаходиться у файлі `use-cases.puml`.

## 3. Актори

**Читач** — може переглядати каталог книг, шукати книги за назвою та переглядати власну історію видач.

**Бібліотекар** — може реєструвати читачів, видавати книги та оформлювати повернення.

У цій версії немає загального актора «Користувач бібліотеки», оскільки він не мав власних прецедентів.

| ID | Прецедент | Актор |

| UC-04 | Повернення книги | Бібліотекар |
