# Промпт 03 — Генерація User Stories

Я виконую лабораторну роботу №2 для проєкту Library Management System.

На основі `spec.md` та `requirements.md` створи історії користувачів (User Stories).

У системі є два основні людські актори: Читач (Reader) і Бібліотекар. Також використовується зовнішній Сервіс сповіщень.

Вимоги до результату:

1. Створи 6 User Stories з ідентифікаторами `US-01` — `US-06`.
2. Використовуй формат: «Як [роль], я хочу [дія], щоб [мета]».
3. Охопи перегляд каталогу, реєстрацію читача, видачу книги, повернення книги, перегляд історії та нагадування.
4. Для кожної історії вкажи пов'язані EARS-вимоги (`REQ-01` — `REQ-10`).
5. Збережи узгодженість із сутностями `Reader`, `Book`, `Author`, `Category`, `Loan`.
6. Не додавай нових сутностей або функцій, яких немає у специфікації.
7. Історії повинні бути короткими, зрозумілими та придатними для перевірки.

Результат оформи у Markdown для файла `user-stories.md`.
