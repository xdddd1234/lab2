# User Stories — Library Management System

## US-01 — Перегляд каталогу

**Як читач, я хочу переглядати каталог і шукати книги за назвою, щоб знайти потрібну книгу.**

Критерії прийняття:
- Система показує назву, автора та категорію книги.
- За непорожнім пошуковим запитом система показує відповідні книги.
- Якщо запит порожній, відображається звичайний каталог.

Пов'язані вимоги: REQ-01, REQ-02.

Use Case: UC-01.

## US-02 — Реєстрація читача

**Як бібліотекар, я хочу реєструвати нових читачів, щоб вони могли брати книги в бібліотеці.**

Критерії прийняття:
- Бібліотекар повинен увійти в систему.
- Нового читача можна зареєструвати з унікальним email.
- Якщо email уже використовується, система показує помилку.
- Без потрібних прав реєстрація не виконується.

Пов'язані вимоги: REQ-03, REQ-04, REQ-13.

Use Case: UC-02.

## US-03 — Видача книги

**Як бібліотекар, я хочу видавати книги зареєстрованим читачам, щоб вести облік того, хто взяв книгу та коли її потрібно повернути.**

Це основна User Story, яку я детально розглядаю в цій лабораторній.

### Критерії прийняття

1. Бібліотекар повинен увійти в систему.
2. Книгу можна видати лише зареєстрованому читачу.
3. Книга не повинна мати іншої активної видачі.
4. Бібліотекар указує дату повернення, яка не може бути раніше поточної дати видачі.
5. Після успішної видачі створюється один запис `Loan`.
6. Якщо будь-яка з перевірок не пройдена, система показує помилку та не створює запис видачі.

### Сценарії

| Сценарій | Опис | Вимога |
|---|---|---|
| SC-01 | Успішна видача книги | REQ-05 |
| SC-02 | Книга вже видана | REQ-06 |
| SC-03 | Неправильна дата повернення | REQ-11 |
| SC-04 | Читач не зареєстрований | REQ-12 |

У всіх сценаріях також застосовується REQ-13 щодо автентифікації та прав доступу.

Пов'язані вимоги: REQ-05, REQ-06, REQ-11, REQ-12, REQ-13.

Use Case: UC-03.

## US-04 — Повернення книги

**Як бібліотекар, я хочу оформлювати повернення книг, щоб система знала, які книги знову доступні.**

Критерії прийняття:
- Бібліотекар повинен увійти в систему.
- Повернення оформлюється для активної видачі.
- Система записує дату повернення в `return_date`.
- Після повернення книга може бути видана іншому читачу.

Пов'язані вимоги: REQ-07, REQ-13.

Use Case: UC-04.

## US-05 — Історія видач

**Як читач, я хочу переглядати історію своїх видач, щоб знати, які книги я брав у бібліотеці.**

Критерії прийняття:
- Читач повинен увійти в систему.
- Система показує тільки його записи `Loan`.
- Історія інших читачів недоступна.

Пов'язані вимоги: REQ-08, REQ-13.

Use Case: UC-05.

## Поза обсягом

US-06 «Надсилання нагадувань» не входить до поточної ітерації.

Автоматичні сповіщення, бронювання книг і штрафи можна розглянути під час подальшого розвитку системи.

## Висновок

У роботі залишено п'ять User Stories. Найдетальніше описано US-03 «Видача книги», для якої створено чотири сценарії з різними результатами.

Це дозволяє перевірити не тільки успішну видачу, а й ситуації, коли система повинна відмовити у виконанні операції.
