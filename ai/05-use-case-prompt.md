# Промпт 05 — Генерація Use Case Diagram

Я виконую лабораторну роботу №2 для проєкту Library Management System.

На основі `spec.md`, `requirements.md`, `user-stories.md` та `scenarios.md` створи UML Use Case Diagram у форматі PlantUML.

## Актори

- Користувач бібліотеки — узагальнений людський актор.
- Читач (Reader) — спеціалізація Користувача бібліотеки.
- Бібліотекар — спеціалізація Користувача бібліотеки.
- Сервіс сповіщень — зовнішня система.

## Варіанти використання

- UC-01 — Перегляд каталогу.
- UC-02 — Реєстрація читача.
- UC-03 — Видача книги.
- UC-04 — Повернення книги.
- UC-05 — Перегляд історії видач.
- UC-06 — Надсилання нагадування.

Дозволяється додати допоміжні варіанти використання для перевірки доступності книги, пошуку книги та перевірки унікальності email.

## Вимоги до діаграми

1. Покажи межу системи Library Management System.
2. Зобрази щонайменше два типи акторів: людину та зовнішній сервіс.
3. Покажи узагальнення акторів: Читач і Бібліотекар успадковуються від Користувача бібліотеки.
4. Використай `<<include>>` для обов'язкової перевірки доступності під час видачі книги.
5. Використай `<<extend>>` для необов'язкового пошуку за назвою під час перегляду каталогу.
6. Покажи зв'язок зовнішнього Сервісу сповіщень із UC-06.
7. Не плутай `include` та `extend`: перший означає обов'язкове повторно використовуване виконання, другий — умовне розширення базового сценарію.
8. Збережи відповідність EARS-вимогам, User Stories та ER-моделі лабораторної №1.
9. Використовуй українські підписи.
10. Результат надай у синтаксисі PlantUML, придатному для рендерингу.
