# Промпт 04 — Генерація Gherkin-сценаріїв

Я виконую лабораторну роботу №2 для проєкту Library Management System.

На основі файлів `spec.md`, `requirements.md` та `user-stories.md` створи сценарії поведінки системи у форматі Gherkin.

У системі є актори: Читач, Бібліотекар і зовнішній Сервіс сповіщень.

Вимоги до результату:

1. Створи 8 Gherkin-сценаріїв з ідентифікаторами `SC-01` — `SC-08`.
2. Використовуй структуру `Feature`, `Scenario`, `Given`, `When`, `Then`, а за потреби `And`.
3. Описуй сценарії українською мовою, але залиш ключові слова Gherkin англійською.
4. Охопи перегляд каталогу, пошук книги, реєстрацію читача, відхилення дубліката email, видачу книги, заборону повторної видачі, повернення книги та перегляд історії.
5. Кожен сценарій повинен мати чіткі передумови, дію та перевірюваний результат.
6. Для кожного сценарію вкажи пов'язані EARS-вимоги та User Stories.
7. Не додавай сутностей, яких немає в ER-моделі лабораторної №1.
8. Вимоги `REQ-09` і `REQ-10`, пов'язані зі сповіщеннями, залиш без окремих Gherkin-сценаріїв для подальшого аналізу неповного покриття в матриці трасування.

Результат оформи у Markdown для файла `scenarios.md`, використовуючи блоки коду `gherkin`.
