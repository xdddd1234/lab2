# Промпт 06 — Матриця трасування вимог

Я виконую лабораторну роботу №2 для проєкту Library Management System.

На основі файлів `spec.md`, `requirements.md`, `user-stories.md`, `scenarios.md` та `use-cases.md` створи матрицю трасування вимог.

## Вхідні артефакти

- EARS-вимоги: REQ-01 — REQ-10.
- User Stories: US-01 — US-06.
- Gherkin-сценарії: SC-01 — SC-08.
- Основні Use Cases: UC-01 — UC-06.

## Вимоги до результату

1. Створи файл `traceability.md` українською мовою.
2. Використовуй Markdown-таблицю.
3. Для кожної EARS-вимоги вкажи пов'язані User Stories, Gherkin-сценарії та Use Cases.
4. Забезпеч зв'язки багато-до-багатьох: одна вимога може відповідати кільком сценаріям, а один сценарій — кільком вимогам.
5. Не вигадуй зв'язків, яких немає у вихідних артефактах.
6. Вимоги REQ-09 і REQ-10 познач як непокриті Gherkin-сценаріями.
7. Поясни, що для перевірки інтеграції із зовнішнім Сервісом сповіщень потрібні окремі інтеграційні тести.
8. Розрізняй наявність Use Case та наявність тестового сценарію: зв'язок із UC не означає, що вимога перевірена тестом.
9. Додай короткий аналіз повноти покриття та вкажи можливі прогалини.
10. Збережи відповідність сутностям і бізнес-правилам лабораторної №1.

Результат повинен бути зрозумілим, придатним для перевірки викладачем та не містити вигаданих даних.
