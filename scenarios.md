# Gherkin-сценарії — Library Management System

Сценарії описують перевірювану поведінку системи на основі EARS-вимог та User Stories.

## SC-01 — Перегляд каталогу книг

**Пов'язані вимоги:** REQ-01  
**User Story:** US-01

```gherkin
Feature: Перегляд каталогу книг

  Scenario: Читач переглядає каталог
    Given у бібліотеці є книги з авторами та категоріями
    When читач відкриває каталог
    Then система відображає список книг
    And для кожної книги показує назву, авторів і категорію
```

## SC-02 — Пошук книги за назвою

**Пов'язані вимоги:** REQ-02  
**User Story:** US-01

```gherkin
Feature: Пошук книг

  Scenario: Читач знаходить книгу за непорожнім запитом
    Given у каталозі є книги "Кобзар" і "Лісова пісня"
    When читач вводить непорожній пошуковий запит "Кобзар"
    Then система відображає книгу "Кобзар"
    And не відображає книгу "Лісова пісня"

```

## SC-03 — Успішна реєстрація читача

**Пов'язані вимоги:** REQ-03  
**User Story:** US-02

```gherkin
Feature: Реєстрація читача

  Scenario: Бібліотекар реєструє нового читача
    Given електронна адреса "reader@example.com" не використовується
    When бібліотекар реєструє читача з цією адресою
    Then система створює запис Reader
    And присвоює читачеві унікальний reader_id
```

## SC-04 — Відхилення дубліката email

**Пов'язані вимоги:** REQ-03, REQ-04  
**User Story:** US-02

```gherkin
Feature: Перевірка унікальності email

  Scenario: Бібліотекар вводить зайняту електронну адресу
    Given у системі існує Reader з email "reader@example.com"
    When бібліотекар намагається зареєструвати іншого читача з цим email
    Then система відхиляє реєстрацію
    And повідомляє про дублювання email
    And не створює нового Reader
```

## SC-05 — Успішна видача книги

**Пов'язані вимоги:** REQ-05, REQ-06  
**User Story:** US-03

```gherkin
Feature: Видача книги

  Scenario: Бібліотекар видає доступну книгу
    Given у системі є зареєстрований Reader
    And книга Book не має активного Loan
    And поточна дата оформлення видачі 2026-10-21
    When бібліотекар оформлює видачу книги з due_date 2026-11-04
    Then система створює новий Loan
    And зберігає reader_id та book_id
    And встановлює loan_date на 2026-10-21
    And встановлює due_date на 2026-11-04
    And залишає return_date відсутньою
    And книга має рівно одну активну видачу

```

## SC-06 — Заборона повторної видачі

**Пов'язані вимоги:** REQ-05, REQ-06  
**User Story:** US-03

```gherkin
Feature: Обмеження активних видач

  Scenario: Бібліотекар намагається повторно видати зайняту книгу
    Given книга Book має активний Loan
    And у цього Loan відсутня return_date
    When бібліотекар намагається оформити ще одну видачу цієї книги
    Then система відхиляє операцію
    And не створює нового Loan
    And кількість активних видач книги залишається рівною одній
```

## SC-07 — Повернення книги

**Пов'язані вимоги:** REQ-07, REQ-06  
**User Story:** US-04

```gherkin
Feature: Повернення книги

  Scenario: Бібліотекар реєструє повернення
    Given книга має активний Loan
    And у цього Loan відсутня return_date
    When бібліотекар реєструє повернення книги 2026-10-21
    Then система встановлює return_date цього Loan на 2026-10-21
    And Loan перестає бути активним
    And запис Loan залишається в історії видач
```

## SC-08 — Перегляд власної історії видач

**Пов'язані вимоги:** REQ-08  
**User Story:** US-05

```gherkin
Feature: Історія видач

  Scenario: Читач переглядає власні видачі
    Given у системі є читач із reader_id 101
    And читач 101 має два записи Loan
    And інший читач має один запис Loan
    When читач 101 відкриває власну історію видач
    Then система відображає рівно два записи Loan читача 101
    And не відображає видачу іншого читача
    And для кожної видачі показує loan_date, due_date та return_date
```
## SC-09 — Відхилення некоректної дати повернення

**Пов'язані вимоги:** REQ-05  
**User Story:** US-03

```gherkin
Feature: Перевірка дати повернення

  Scenario: Бібліотекар указує дату повернення раніше дати видачі
    Given у системі є зареєстрований Reader
    And книга Book не має активного Loan
    And поточна дата оформлення видачі 2026-10-21
    When бібліотекар оформлює видачу з due_date 2026-10-20
    Then система відхиляє операцію
    And повідомляє про некоректну дату повернення
    And не створює новий Loan
```

Таким чином, 8 із 10 вимог мають сценарне покриття. Деякі вимоги перевіряються кількома сценаріями, а окремі сценарії перевіряють декілька вимог.
