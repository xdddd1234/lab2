# Gherkin-сценарії — Видача книги

## User Story US-03

**Як бібліотекар, я хочу видавати книги зареєстрованим читачам, щоб вести облік того, хто взяв книгу та коли її потрібно повернути.**

## Feature: Видача книги (UC-03)

**Передумова:** бібліотекар увійшов у систему.

### SC-01 — Успішна видача книги

**Дано** бібліотекар увійшов у систему

**І** читач з `reader_id = 15` зареєстрований

**І** книга з `book_id = 101` доступна для видачі

**І** поточна дата — 21.10.2026

**Коли** бібліотекар оформлює видачу цієї книги читачу з датою повернення 04.11.2026

**Тоді** система створює один новий запис `Loan`

**І** встановлює `loan_date = 21.10.2026`

**І** встановлює `due_date = 04.11.2026`

**І** залишає `return_date` порожнім

**І** показує повідомлення про успішну видачу

### SC-02 — Книга вже видана

**Дано** бібліотекар увійшов у систему

**І** читач з `reader_id = 15` зареєстрований

**І** книга з `book_id = 101` вже має активний запис `Loan`

**Коли** бібліотекар намагається видати цю книгу ще раз

**Тоді** система відмовляє у видачі

**І** показує повідомлення «Книга вже видана»

**І** не створює новий запис `Loan`

**І** не змінює наявний активний запис

### SC-03 — Неправильна дата повернення

**Дано** бібліотекар увійшов у систему

**І** читач з `reader_id = 15` зареєстрований

**І** книга з `book_id = 101` доступна

**І** поточна дата — 21.10.2026

**Коли** бібліотекар указує дату повернення 20.10.2026

**Тоді** система відмовляє у видачі

**І** показує повідомлення «Дата повернення не може бути раніше дати видачі»

**І** не створює запис `Loan`

### SC-04 — Читач не зареєстрований

**Дано** бібліотекар увійшов у систему

**І** книги з `book_id = 101` немає серед активних видач

**І** читача з `reader_id = 9999` немає в системі

**Коли** бібліотекар намагається видати книгу цьому читачу з датою повернення 04.11.2026

**Тоді** система відмовляє у видачі

**І** показує повідомлення «Читача не знайдено»

**І** не створює запис `Loan`

## Зв'язок сценаріїв із вимогами

| Сценарій | Що перевіряє |
|---|---|
| SC-01 | Успішне створення видачі |
| SC-02 | Заборона повторної видачі зайнятої книги |
| SC-03 | Перевірка правильної дати повернення |
| SC-04 | Перевірка реєстрації читача |

Усі чотири сценарії стосуються UC-03 «Видача книги» та User Story US-03.

Для решти прецедентів у цій ітерації використовується UML Use Case Diagram. Їхні детальні Gherkin-сценарії не входять до цієї роботи.
